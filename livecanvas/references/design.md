# 封面、分镜与动效

设计来源：用户指定的 [Emil Kowalski animate](https://github.com/emilkowalski/skills/blob/main/skills/animate/SKILL.md)。保留有目的、连续、克制的动作原则，适配 Remotion 解释性短动画；不机械套用交互组件的工具选择或 300ms 时长上限。

## 先决定如何讲，再决定画什么图

把事实变成能看懂的动作。先写一句结论，再选择视觉主角和动作；默认加入主题相关的图片、PNG、emoji 或图标。只有资料本身适合时才用坐标图，不把每个主题都变成“标题 + 大数字 + 柱形/折线”。

成套策划先列每张的主体、核心结论和来源，检查是否覆盖材料与用户关心的重点。内容丰富时按重要性与用户重点取舍，不仅因为价格、排名等容易做成大数字，就让它们占据整套主线。

同一套固定色彩角色、字体层级与图形语言，根据关系选择构图：比例用比例图，协作用流程，多维比较用坐标图。版式变化服务信息，不强求每张都不同，也不把所有内容装进同一种卡片。

按内容选择，可组合但不必全部使用：

| 要表达的内容 | 画面与动作 | 适合的素材 |
| --- | --- | --- |
| 多对象、多条件比较 | 在共同坐标中呈现对象与档位，逐步揭示关系 | 原始点位、折线、散点、条件标签 |
| 产品差异 | 两个实物并列、焦点依次切换、对应能力卡片展开 | 产品透明 PNG、局部特写、功能图标 |
| 发展历程 | 主体沿年份节点移动，节点带出事件或数字 | 列车、里程碑、档案照片 |
| 数量与占比 | 对象逐批加入、排列或改变状态 | 汽车、人形、咖啡杯、房屋图标 |
| 季节变化 | 同一场景切换季节，温度与月份联动 | 城市照片、太阳/雨/雪 emoji |
| 排名或竞赛 | 实物/头像带着标签交换位置，保留清楚的计量依据 | 品牌杯子、国旗、运动员照片、奖牌 |
| 原理或流程 | 部件拆分组合、路径推进、前后状态对照 | 原创示意图、物件 PNG、步骤插画 |
| 空间扩展 | 有依据的地图区域逐步点亮，地点卡片出现 | 地图、城市剪影、地点照片 |

如用地图或竞赛轨道做比喻，明确“示意”；不能让列车速度冒充实际速度、图标数冒充未核实的总数、区域点亮冒充真实通车线路。

## 标题与配图文案

让标题直接回答“发生了什么、多少、与谁相比”。优先保留具体名词、数字和动词；不用抽象口号包装已经很清楚的数据。以下只示范写法，数字必须按本次来源核实，不能作为可复用事实。

| 避免的写法 | 推荐写法 |
| --- | --- |
| 给长任务，更长的输出空间 | 输出上限 1M tokens |
| 更强性能，更低门槛 | 首发任务成本低 39% |
| 更低价格，让使用更轻松 | 价格降至 1/10 |
| 不确定时，更愿意说不知道 | 幻觉率 15% |
| 榜首附近，放在一起看 | Text Arena 前五 |
| 让工程收益，落到真实资源 | 已释放 300+ TiB 内存 |
| 三个变化，读懂某某产品 | 产品名、版本号或具体指标名称 |

- 比较词必须有对象和口径。“比肩某模型”须在副标题写出测试名称与双方分数；不能把单项成绩改写成全面性能相同。“成本低 39%”须紧邻说明比较对象及首发优惠条件。
- 排名写清榜单名称与日期；初步结果保留“暂列/初步”。区分百分比与百分点、输出上限与上下文窗口、已实现与预计。精简不能删掉会改变结论的限定条件；较长的方法说明放在脚注或来源页。
- 每张配图描述用一到两句，直接写主体、指标和必要比较。避免“这张图告诉我们”“不只是……更是……”等引导句，也不重复堆叠标题。中英文使用相同事实范围，各自采用自然的短句。
- “不花哨”是减少妨碍阅读的装饰，不等于删除官方产品图、品牌标识、有效的解释图或全部配色。文案改写与视觉重做分别判断；用户只要求改文案时，不替换已选主题和内容。

## 封面本身是完整作品

封面优先让产品名、版本号或核心对象成为视觉主角，呈现关键结论和必要的单位/来源/截止日。把“登场感”“冲击力”等描述转成尺度、位置、留白和入场动作；只有用户明确指定为文案时才写进画面，不让效果词挤占主体。核心视觉可以是图片组合、代表场景、图标阵列或完整图表。静态观看也能理解，不依赖上一幕补齐关键信息。封面取视频中的稳定完整帧，不做与视频无关的额外海报。

默认 3:4 竖版、1080 宽、安全边距约 72–88 px；中文字和数字保证手机可读。图片有明确主次，统一光影、描边或抠图处理。默认一个视觉主角配少量辅助元素，避免为了丰富而塞满素材。

## 短分镜

制作前写下每段的时间、主体动作、要解释的事实、素材和稳定保留的文字。约 3 秒可采用一个场景内的连续动作；信息更多时调整时长或拆成多张 Live Photo，不在三秒内硬塞多页长文。

| 时间示例 | 叙事任务 |
| --- | --- |
| 0.00–0.25 s | 主题已可读，视觉主角进入或出现轻微状态变化 |
| 0.25–2.00 s | 主体动作解释过程：驶过节点、成组出现、图片对照或季节切换；数字与事实同步 |
| 2.00–3.00 s | 收束成完整封面，让结论有阅读时间；默认第 78 帧取封面 |

节奏可改。封面前保留可读停留段；改时长须同步 composition、render.mjs 的 coverFrame 和抽帧位置。多幕场景通过同一主体或空间位置衔接，不用无意义整屏闪白与突兀跳切。不要求所有元素一直动，不强制循环。

## 有目的的动效

- Explanation：动作解释比较、变化或机制。装饰可轻微呼吸、光泽或漂浮，但不能抢过主体。
- 图片主角可平移、裁切揭示、轻微旋转、0.95→1 缩放、前后景轻视差；对象复制/排列可解释数量。不是只给图片淡入就算完成叙事。
- 阅读中的标题、单位和计量基准稳定；文字用重点切换、分步呈现，不让整段文字滚动或弹跳。
- 数字确有变化时可用逐位滚动；用户指定滚动则采用。单位、小数点和布局保持稳定，最终数值与来源一致并留出完整停留段。不让所有数字都从零滚起，避免把版本号或恒定事实表现成测量变化。
- 区分滚动排版与量化过程：计数或时间序列应与图形使用同一实际值；纯数字换位只是过渡，不把混合数字作为某一帧的实测值或据此驱动图形。检查看似新数字的中间帧、位数变化、负号和裁切，避免停留造成误读。
- 标注进入可从 150–250ms 起步，错开 30–80ms。进入使用 `Easing.bezier(0.23, 1, 0.32, 1)`，对象移动可用 `Easing.bezier(0.77, 0, 0.175, 1)`。
- 数据时间进度线性，比例和数值不加弹簧过冲。装饰动作的曲线不改变数据对应的位置或面积。
- 全部动画由 frame/fps 决定；不使用 CSS animation、墙钟、setInterval、未固定随机数或自由播放的动画图片。

## 量化图形不失真

图标阵列明确“每个代表多少”，部分图标按比例填充或说明取整，不凭好看凑数。气温变化不换算为摄氏百分比；尺寸比较说明编码的是长度还是面积。实物插画大小若不编码数值，不能与计量图混淆。

多对象、多档位或多条件是材料的重点时，保留相关对象、基准与条件，不把关系图缩成孤立分数。成本与性能等双变量比较保留两条轴、单位、线性或对数尺度和图例；详细证据要求见 [数据与口径](data.md#比较图与原始点位)。

时间曲线 X 按真实日期，Y 轴稳定；缺测断线，插值不能标成实测。排名换位沿合理路径衔接，不让中间位置产生错误的最终排名。预测、示意和生成插画明确区分于实测和真实现场。

## 预览

检查封面、动作中段、每个转场和结尾；图片/emoji 加载、透明底、裁切、遮挡、数值与图片对应关系都要核对。视频不能读取观看者 Reduce Motion 设置，以静态封面提供替代；网页预览需要时提供减少动效/静态开关。代码通过不等于画面通过。
